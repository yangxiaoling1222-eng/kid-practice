# 每日练习（大班）

给幼儿园大班孩子的每日小练习，单文件网页，手机/平板浏览器直接打开即用，无需联网安装。

🔗 在线使用：https://yangxiaoling1222-eng.github.io/kid-practice/

## 功能

**数学 · 10 以内加减法**
- 7 种题型：加法、减法、填空、比大小、连加连减、加减混合、数的分解
- 难度三档：5 以内 / 标准 / 全题型
- 每日题量 1–60 可自定义，首页「改题量」随时改
- 孩子点 0–10 数字键盘作答，自动判对错、计时、算正确率

**拼音 · 朗读卡**
- 平翘舌 38 组（zh/z、ch/c、sh/s）
- 前后鼻音 37 组（an·ang、en·eng、in·ing）
- n/l 14 组、b·d 与 p·q 12 组、四声调 10 组、整体认读 16 个、词语朗读 160 张
- 家长判断「读对了 / 再练一次」，读错的进薄弱池，次日优先再出现

**统计**
- 连续打卡、近 14 天正确率双折线、35 天打卡热力日历
- 数学分题型正确率、拼音分类掌握率、易错拼音 TOP
- 数学错题本（一键重做）、每日记录可点开看当天错在哪

## 机制

- 每天题目自动不一样：以日期为随机种子（`hash(日期|类型|offset)` + mulberry32）
- 「换一组」= offset + 1，立刻换新题
- 错题加权复习：读错的音节记入薄弱池，后续优先抽取

## 数据

练习记录存在浏览器 localStorage（key `kidp_v1`），**不会上传服务器**。换设备请在设置里先导出 JSON 再导入。
